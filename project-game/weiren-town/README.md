# 伪人小镇

基于 Godot 4.6.3 与 GDScript 的小镇恐怖探索原型。玩家在汽车故障后进入小镇，搜集物资与维修工具、修复车辆，并应对角色互动和规则触发的怪物遭遇。

## 实现重点

- **探索与资源循环**：场景物品与家具交互、背包、钥匙门锁、有限物资与进度持久化。
- **实体车辆维修**：检查车况，完成轮胎、电瓶、线圈与皮带的拆装和更换。
- **角色与怪物**：B 的对话、视线和注视表现，以及维尔的可见、追踪与攻击表现。
- **外部离场镜头**：维修完成后驶离小镇，摄影机脱离玩家视角；支持暂停、跳过、返回菜单和完成状态保存。
- **工程验证**：原子保存、旧档迁移、故障边界与独立导出资源检查，区分自动化结果与人工验收。

## 制作与边界

项目结合程序化建模、材质制作、AI 辅助生成与像素化整理、本地合成音效，并使用已知第三方字体及纸张纹理。制作来源分别记录，不将全部内容描述为手工原创或无第三方资源。

当前为开发中原型，完整剧情、玩法平衡与体验持续迭代。维修验证使用 Godot 输入及到达位置夹具加速，不等同于连续人工步行通关；声音试听、广泛硬件兼容及 OS 鼠标捕获等仍需进一步验收。
