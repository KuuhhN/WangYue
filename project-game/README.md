# 游戏作品

## 《伪人小镇》

基于Godot4.6.3的小镇恐怖探索原型，结合资源搜集、实体车辆维修、角色互动与规则触发的怪物遭遇。

[查看项目介绍](weiren-town/)。Windows Demo 0.1.0 RC1 已完成独立导出与运行验证，目前正在准备公开下载附件。
